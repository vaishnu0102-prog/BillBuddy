# BillBuddy

BillBuddy is a smart bill and expense management application designed to help users track bills, manage expenses, monitor budgets, and understand their spending through analytics and intelligent insights.

## Status

🚧 Currently under development.

## Planned Features

- User authentication
- Bill management
- Expense tracking
- Budget management
- Dashboard
- Spending analytics
- Bill reminders
- AI-powered financial insights

## Tech Stack

- React
- Node.js
- Express
- PostgreSQL
- Prisma
- Tailwind CSS
